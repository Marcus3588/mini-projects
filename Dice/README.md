# 🎲 Dice Roll

A simple and fun dice rolling simulator.

## Features

- [ ] Roll a single die (1-6)
- [ ] Display dice face with dots/numbers
- [ ] Click to roll animation
- [ ] Random number generation
- [ ] Clean, responsive design
